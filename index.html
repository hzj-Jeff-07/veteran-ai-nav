从转业第一天到拿到第一份 AI 相关 offer,这条路怎么走。

STAGE 01 1-2 月

心态 + 计算机基础

收心、立纪律。装系统、敲命令、看懂程序员说的话。

  • • Linux 入门(命令行 / 文件系统)
  • • 计算机网络基本概念
  • • Git / Markdown / 终端
  • • 英语阅读不犯怵

STAGE 02 3-6 月

Python 编程筑基

不学 Python 就不要谈 AI。这是绕不开的硬功夫。

  • • Python 语法 + 数据结构
  • • 函数、模块、面向对象
  • • requests / pandas 实战
  • • 写 3 个能跑的小项目
产出:GitHub 上 3 个项目
STAGE 03 3-6 月

AI 工程化入门

先学怎么用 AI 解决问题,再学背后的数学原理。

  • • 大模型 API 调用(Claude / GPT)
  • • Prompt 工程与 RAG
  • • LangChain / 向量数据库
  • • MCP / Agent 工程
产出:1 个 AI 应用上线
STAGE 04 长期

AI 安全 / 网络安全

真正的护城河方向。退役军人的纪律性 + 安全=天然合身。

  • • 网络安全基础(渗透 / 防御)
  • • 大模型安全(Prompt 注入 / 越狱)
  • • Red Team for AI
  • • CTF / HTB 实战
目标:进入大厂安全团队

— FAQ

常见问题

退役没学过编程,真的能转 AI 吗? +

能。但请抛弃"3 个月转行年薪 30 万"的幻想,那是培训机构的话术。 真实路径是 1.5-3 年系统学习 + 持续输出作品。 退役军人最大的优势不是 IQ,是纪律和抗压——这恰好是大多数自学者最缺的。

学历不够,大厂会要吗? +

学历是门槛但不是天花板。中小厂可以靠作品集敲门;大厂建议走"专升本 → 考研"路径。 退役军人有专升本政策红利,这条路比想象中可行。

要不要报某某万元课? +

99% 的情况下:不要。本站列的免费资源已经覆盖 95% 的学习路径。 付费课的真正价值是"陪伴 + 答疑 + 督促",不是知识本身。 如果你能死磕主线,你不需要这种陪伴。
