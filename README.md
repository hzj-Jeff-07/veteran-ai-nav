# 退役军人 AI 学习导航站

> 退役不退志,从零到 AI,这里有路。
> 一个为退役军人量身定制的 AI 自学路径图与精选资源导航。

## 项目定位

- **JTBD**:帮退役军人转行 AI 解决三件事——路径焦虑 / 防被骗 / 找同路人
- **核心承诺**:免费资源优先,不卖课,不带货
- **作者**:一名 2002 年生的退役军人(@龙渊),大专在读、备考 2027 专升本

## 技术栈

- 纯 HTML + Tailwind CDN(零构建)
- 部署:GitHub Pages
- 无后端、无数据库、无用户系统

## 本地预览

直接双击 `index.html`,或用任何静态服务器:

```bash
# Python 3
python -m http.server 8000

# Node
npx serve .
```

总投入 ≤ 30 小时;**2026-05-31 必须 v1 上线**;
冷启动 ≤ 2 周,数据不起色则归档,不持续优化。
